# Shri Digambar Mahaveer Jain Temple (HAL)

This website is an information and visit-planning resource for Shri Digambar Mahaveer Jain Temple (HAL) in Bengaluru. It introduces the temple and its traditions, shares darshan timings, location and contact details, and showcases temple photographs and upcoming events.

The website is available in English, Hindi and Kannada to help devotees and visitors find the information they need before visiting the temple.
